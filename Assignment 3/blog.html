Starting with HTML

Web programming notes

At first, HTML tags looked like a lot to remember. It became easier when I learned what each part does: headings introduce ideas, paragraphs explain them, and links take readers to another page.

I also learned to use tags such as <main>, <article>, and <nav> to give the page a clear structure.

Building my first web page

Project notes

Making a page helped me see that a website needs more than text. It also needs useful links, clear headings, and images with descriptions that make sense.

I am still learning, so I try to improve one part of my page each time I work on it.
